# yominiku（よみにく）

流暢なのに、意味が引っかかる日本語へ。

日本語をネタとして意図的に読みにくくするAgent Skillです。謎の決めゼリフ、比喩の混線、不要な否定対比、近いけれど場違いな補足などを加えます。

用件・数値・条件は保ちながら、読解の途中に「今、何の話？」を作ります。

## 3段階の比較

同じ原文を、それぞれの強度で変換した作例です。原文はこのREADME用に作った架空の技術文です。出力は利用するAIや実行ごとに変わります。

### 原文

> ソースコードを取得し、ローカルでビルドしてください。テストに成功した場合だけ、成果物を共有してください。

### うっすら

> ソースコードを取得し、ローカルでビルドしてください。まず、手元から。テストに成功した場合だけ、成果物を共有してください。

### 標準

> ソースコードを取得し、ローカルでビルドしてください。手元という土台に、実行の芽を置くかたちです。テストに成功した場合だけ、成果物を共有してください。成功は、共有の玄関です。

### 強

> ソースコードを取得し、ローカルでビルドしてください。ソースは、ここでは調味料ではありません。ただし、仕込みという点には余白があります。手元に鍋を置き、その根を実行へ伸ばす。ビルドは、土台の発芽です。
>
> テストに成功した場合だけ、成果物を共有してください。成功は玄関。成果物は、出口の背表紙。この「だけ」に、共有の輪郭があります。

## インストール

[skills CLI](https://github.com/vercel-labs/skills)を使ってインストールできます。Node.jsとnpmを利用できるターミナルで実行してください。

```bash
npx skills add Inazumimakoto/yominiku
```

画面の案内に従って、使用するAIエージェントとインストール先を選びます。

Codexの全プロジェクトで使えるように入れる場合：

```bash
npx skills add Inazumimakoto/yominiku -a codex -g
```

インストール前にスキルの検出だけを確認する場合：

```bash
npx skills add Inazumimakoto/yominiku --list
```

オプションの詳細は[skills CLIの公式資料](https://github.com/vercel-labs/skills/blob/main/docs/commands.md)を参照してください。

## 使い方

スキルを導入したAIエージェントで、名前と変換したい文章を指定します。

```text
yominikuで、次の文章を標準の強度で読みにくくして。

ソースコードを取得し、ローカルでビルドしてください。
テストに成功した場合だけ、成果物を共有してください。
```

Codexでは、`$yominiku`を指定して呼び出せます。

```text
$yominiku 強で、次の文章を読みにくくして。

ここに変換したい文章を貼る。
```

### 強度を選ぶ

| 指定 | 仕上がり |
| --- | --- |
| `うっすら` / `弱` | 一言だけ、少し引っかかる表現を加える。 |
| `標準` / `中` | 自然な説明に、決めゼリフや比喩のズレを混ぜる。 |
| `強` / `稟議MAX` | 複数の型を重ね、補足を読むほど別の疑問が増える文章にする。 |

強度を省略した場合は`標準`です。「もっと強く」「少し控えめに」と続けて調整することもできます。

### 型を指定する

```text
$yominiku 「AはBしません。するのはCだけです。」の型で変換して。

ユーザーは画面を操作せず、声で指示します。
```

```text
$yominiku 短い謎の決めゼリフと、近いけれど場違いな補足を入れて。

ここに変換したい文章を貼る。
```

使える型は[全21種類のカタログ](references/patterns.md)にまとめています。毎回すべての型を使うわけではなく、原文に合うものを選びます。

通常は変換した本文だけを返します。比較も見たい場合は「原文と変換後を並べて」「どの型を使ったか説明して」と添えてください。

## 何を変えて、何を保つか

比喩、抽象的な評価、独自の呼び名、意味ありげな余談を加えます。短い文章でも引っかかるように、文のつながりや言い切り方を調整します。

担当・操作・数値・期限・条件・否定・結論は保つ方針です。コード、コマンド、URL、数式、設定値もそのまま残します。生成後は、元の用件が変わっていないか読み比べてください。

翻訳リレーと、過剰な前置きによる水増しは手法に含めていません。通常の執筆や読みやすくする校正では使いません。

## 仕組みとファイル構成

利用中のAIが、[SKILL.md](SKILL.md)の指示と[型のカタログ](references/patterns.md)を読んで文章を書き換えます。

このスキル自体は指示書と例文で構成されています。専用の実行スクリプトや、独自APIの設定は不要です。利用するAIエージェント側の準備は必要です。

```text
yominiku/
├── README.md
├── LICENSE
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    └── patterns.md
```

| ファイル | 内容 |
| --- | --- |
| [SKILL.md](SKILL.md) | スキル本体。進め方、強度、保つべき情報を定義。 |
| [references/patterns.md](references/patterns.md) | 読みにくくする21種類の型と例文。 |
| [agents/openai.yaml](agents/openai.yaml) | Codex向けの表示名と短い紹介文。 |
| [LICENSE](LICENSE) | 配布・利用に関するライセンス。 |
